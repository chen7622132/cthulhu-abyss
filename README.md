# 尘封档案 · Abyssal Archive

> 一份民国十七年（1928）的渔船失踪调查卷宗。
> 你是复核人。上头要你把前任的结论核一遍。
>
> **非授权人员不得开启。**

一个在浏览器里读的交互式档案。没有游戏机制，没有得分，没有通关条件——只有一份卷宗，和逐渐不对劲的纸。

---

## 怎么看

直接在浏览器打开 `index.html`（推荐 Chrome / Edge，桌面端；需要鼠标）。

建议：**戴上耳机，关灯，把浏览器开全屏（F11）**，然后慢慢看。

全程约 10 分钟。第一遍请按顺序读完，不要跳。

> 如果你对连续图形变化敏感，可在系统设置里开启「减少动态效果」，或在地址后加 `?quiet=1`；
> 阅读中随时按 `Esc` 可合卷。

## 里面有什么

- **七份证物**：立案文书 / 现场照片 / 村民笔录 / 渔船档案 / 生还者讯问 / 回收物清单 / 附录·未归档
- **一份会退化的文本**：越往下读，纸越潮、字越歪。在同一页停留越久，那一段烂得越快
- **一个写铅笔字的人**：他不是官员，是被临时征来抄档案的教员
- **一些会消失的东西**：看见了，然后没了。回去看，那里什么都没有
- **一只横瞳的眼睛**：出现在最后
- **一次轮回**

## 技术

纯静态，零依赖，零构建，零图片素材。

| 部分 | 做法 |
|---|---|
| 纸张／印章／装订孔／水渍 | 全部 CSS 渐变与阴影，无图片 |
| 颗粒噪点 | Canvas 逐帧生成 `ImageData` |
| 文字退化 | 单一变量 `--corruption`（0→1）驱动字距、对比、水渍、整体位移 |
| 整体漂移 | SVG `feTurbulence` + `feDisplacementMap` |
| 眼睛 | **GLSL 光线步进（SDF Ray Marching）**，程序化生成眼球、角膜、虹膜纤维、血管、横向瞳孔、镜面高光；无模型、无贴图 |
| 声音 | Web Audio 实时合成（拍频 drone、纸页摩擦、水滴、次声），无音频文件 |
| 字体 | 系统字体栈：仿宋（公文）／楷体（批注）／Courier（英文） |

眼睛的立体感来自五件事：真实法线、角膜折射、**角膜不是球**（双球平滑融合）、镜面高光、视差错位。
参考实现思路（均 MIT）：
- `lighttransport/procedural-eyeball-shader`
- `TanerTalas/fire-eye`

## 无障碍

- 全程无每秒 3 次以上的闪烁（WCAG 2.3.1）
- 支持系统级 `prefers-reduced-motion`，自动降级为「静阅」
- 地址加 `?quiet=1` 强制静阅
- `Esc` 随时合卷
- 正文为真实 DOM 文本，可选中、可搜索、可被读屏软件读取（眼睛段除外）

## 目录

```
index.html
css/
  base.css        基础、光标灯、噪点、卷宗封面
  archive.css     目录、七份证物版式、边注、附件层
  corruption.css  退化系统、间歇污染
  eye.css         眼睛层、阅卷记录、轮回、归档
js/
  content.js      文本数据、闪现配置、设备信息、存档
  audio.js        Web Audio 合成
  corruption.js   退化主控、光标灯、停留计时
  glitch.js       间歇污染（出现→模糊→消失）
  reveal.js       目录高亮、放大镜附件、回看验证
  eye.js          SDF 光线步进眼睛 + 30 秒节奏
  endgame.js      触发、阅卷记录、瞳孔开洞、轮回
  main.js         入口
check.js          结构自检（node check.js）
check_html.py     HTML 标签平衡自检
```

## 开发自检

```bash
python3 check_html.py  # HTML 标签平衡
```

## 关于

设定参考了 1928 年前后福建沿海的真实材料：船牌与族邻保结制度、帆面书写规范、「一船为盗同结连坐」、讨海禁忌（忌说「翻」「覆」「倒」）、「海醮」与「王爷船」。

「Ph'nglui mglw'nafh Cthulhu R'lyeh wgah'nagl fhtagn」及其中译出自 H.P. Lovecraft《克苏鲁的呼唤》（1928）。
